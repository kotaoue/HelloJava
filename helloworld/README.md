# helloworld

A minimal Java Hello World program.

## Features

* **Zero dependencies** — Runs with only the JDK; no external libraries or build tools required
* **Cross-platform** — Runs anywhere a JVM is installed (Linux, macOS, Windows)
* **Simple compilation** — Build and run with just `javac` and `java` commands
* **Standard output** — Uses `System.out.println` for straightforward console output

## How to run

Compile and run with the following commands:

```sh
javac HelloWorld.java
java HelloWorld
```

Expected output:

```text
Hello, World!
```
